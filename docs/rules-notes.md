# 세피리아 아티팩트·석판 배치 규칙 정리 (1.0 기준)

## 1. 배낭(인벤토리)
- 가로 6칸 고정. 기본 24칸(4행), 최대 42칸(7행)까지 확장.
- 칸 수가 6의 배수가 아니면 마지막 행이 부분 행 → 열마다 "최하단" 위치가 달라짐 (차양 등에 영향).
- 아티팩트·석판 모두 1칸 차지 (별도 footprint 없음).

## 2. 아티팩트
- 기본 레벨 0. 별(★) = 레벨 상한. 상한 초과분은 무효.
- 레벨 -1 이하 → 효과 비활성화 (단, 콤보 태그 카운트는 유지).
- #태그: 같은 태그 개수로 콤보 효과 발동 (보통 2~6개 구간). 콤보 카운트는 석판 효과 적용 전 계산 → 비활성 아티팩트도 콤보에 기여.
- <제약> 아티팩트: 조건 만족 시만 효과.
  - 인벤토리 가장자리 (용골 파편, 초록 잉크병, 축사의 검집)
  - 최하단 (은접시)
  - 최상단 (마법 당근)
  - 안쪽 (가시덤불)
  - 양옆 모두 빈칸 (차가운 자물쇠)
  - 무기 전용 (검방패/대검/석궁/도/봉 등)
- 위치 상호작용 아티팩트: 하얀 종이(양옆 동일 콤보면 +1), 레이에 별조각(왼쪽 칸 마법서 MP 감소), 헌신의 휘장(같은 가로줄 동료), 캘세더니 열쇠(가로줄에 따라 태그 변경).

## 3. 석판
- 자기 자신은 레벨 없음 → 석판 위에 -1 떨어져도 무의미. 석판끼리 페널티 칸을 덮어 상쇄 가능.
- 효과 3종: 레벨 +N / 레벨 -N / 제약 무시 ("무시").
- 배낭 밖 칸은 그냥 무효 → 가장자리·구석 배치로 페널티 회피.
- 회전: 대부분 90° 회전 가능. "회전 불가" 석판 존재.
- 활성화 조건 있는 석판: 최하단(선의), 최상단(차양), 왼쪽/오른쪽 끝(정의), 왼쪽 끝(깃발).
- 패턴 종류: 인접 1칸, 대각선, 나이트 행마, 행 전체(기반), 열 전체(동시성), 대각선 전체(반항), 최상단+최하단 전체(경계), 각 열 최하단(차양), 체스판(저주).
- 등급: 일반(합0~2) / 고급(합0~4) / 희귀(합2~6) / 전설(6+) / 영원.
- 석판 합성(조합) 시스템 존재 — 두 석판 패턴 합침 (툴에서는 1차 미지원 가능).

## 5. 최적화 목표 (툴 설계용)
- 목적함수: 핵심 아티팩트의 (min(레벨, 상한)) 합 최대화, 가중치 부여 가능.
- 제약: 레벨<0 금지(또는 비핵심 아이템 허용), 아티팩트 위치 제약 만족, 석판 활성화 조건, 회전 불가.
- 콤보 태그 유지.
- 참고 툴: sephiria.tools/bag-planner (수동 플래너, 자동 최적화 없음).
